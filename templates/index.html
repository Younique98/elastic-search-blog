RetrievalKit is self-hostable hybrid retrieval infrastructure for engineering teams building RAG pipelines and AI agents on Elasticsearch.

Every query below runs BM25 lexical search and Elasticsearch's built-in semantic retrieval in parallel, merged with Reciprocal Rank Fusion — so a query like why do requests fail under load can surface a doc about connection pool exhaustion even if it never uses those words. No second vector database, no external embedding service: the semantic index lives inside the same Elasticsearch cluster you already operate.

This search box runs against a sample engineering-documentation corpus so you can try it live. Manage documents from the admin panel; every save updates the index immediately.
